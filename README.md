# 🏕️ 캠프 배치 — 캠핑 사이트·장비 배치 시뮬레이터

캠핑 사이트의 크기(가로×세로)를 정하고, 가진 텐트·타프·야전침대·테이블·의자·카고박스·화로대·차량을
실제 cm 규격으로 올려 **겹침·가이라인 여유·사이트 이탈**을 확인하며 배치를 미리 그려보는 웹앱입니다.

- 주소: https://ysj0410-max.github.io/camp-layout-sim/
- 서버 없음 · 설치 없음 · 스마트폰/PC 브라우저에서 바로 사용
- 저장은 그 브라우저(localStorage)에만 됩니다. 기기를 바꾸려면 **JSON 내보내기 → 불러오기**로 옮기세요.

## 기본 장비
- 텐트 7종 실제 규격: 야크돔 450, 위켄트립 모델V, 제드 티맥스 EX, 트레블첵 라움 미니, 폴러 투맨, 네이처하이크 빌리지 5.0, 지오에어 4
- 타프(렉타·헥사), 가구(야전침대·테이블·IGT·체어), 수납(카고박스·쿨러·쉘프), 화기(화로대), 차량, 장애물(나무 기둥·전기 배전함)
- 장비는 언제든 **＋ 내 장비 cm로 등록**으로 추가하고, 카드의 ✎로 수정/삭제할 수 있습니다.

## 배치 규칙
- **텐트·타프는 바닥 레이어**, 가구·수납·화기는 그 위 레이어로 그려집니다. → 텐트 안에 침대·테이블을 놓는 **내부 배치**는 겹침 경고가 없습니다.
- 경고가 뜨는 경우: **텐트↔텐트/타프**, **가구·수납·화기끼리**, **차량이 끼는 겹침**, **장애물(나무·배전함)과의 겹침**, **사이트 밖 이탈**.

## 조작
- 카드 탭 → 배치 / 드래그 → 이동(10cm 스냅) / 선택 후 **↻ 손잡이** 또는 −15°·+15°·+90°·0° → 회전
- 두 손가락 확대·축소, 마우스 휠, 우측 위 ＋/−/맞춤 버튼
- 선택 장비의 **가로·세로·가이(cm)** 를 그 자리에서 수정, **이름·모양**에서 모양·출입문·색상 수정
- **✨ 자동 배치**: 차량은 아래쪽 주차, 큰 텐트는 위쪽, 가구는 텐트 안에 줄 맞춰 정리 (장애물 회피)
- **💨 바람**: 켜기/끄기, 45°씩 회전. 화로대·난로를 놓으면 바람이 불어가는 쪽으로 연기가 표시됩니다.
- **배치안** 탭에 이름 붙여 여러 개 저장/불러오기/삭제, **도면 PNG**로 이미지 저장, **JSON** 백업/복원

## 파일
- `index.html` — 화면 구조
- `styles.css` — 반응형 스타일 (모바일 하단 시트 / PC 우측 패널)
- `app.js` — 상태·기하 계산(겹침 판정)·캔버스 렌더·자동 배치·저장
