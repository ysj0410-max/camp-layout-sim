# 🏕️ 캠프 배치 — 캠핑 사이트·장비 배치 시뮬레이터

캠핑 사이트의 크기(가로×세로)를 정하고, 가진 텐트·타프·야전침대·테이블·의자·카고박스·화로대·차량을
실제 cm 규격으로 올려 **겹침·가이라인 여유·사이트 이탈**을 확인하며 배치를 미리 그려보는 웹앱입니다.

- 주소: https://ysj0410-max.github.io/camp-layout-sim/
- 서버 없음 · 설치 없음 · 스마트폰/PC 브라우저에서 바로 사용
- 저장은 그 브라우저(localStorage)에만 됩니다. 기기를 바꾸려면 **JSON 내보내기 → 불러오기**로 옮기세요.

## 기본 장비
- 텐트 7종 실제 규격: 야크돔 450, 위켄트립 모델V, 제드 티맥스 EX, 트레블첵 라움 미니, 폴러 투맨, 네이처하이크 빌리지 5.0, 지오에어 4
- 타프(렉타·헥사), 가구(야전침대·테이블·IGT·체어), 수납(카고박스·쿨러·쉘프), 화기(화로대), 차량, 장애물(나무 기둥·전기 배전함)
- 장비는 언제든 **＋ 내 장비 cm로 등록**으로 추가하고, 카드의 ✎로 수정/삭제할 수 있습니다.

## 배치 규칙
- **텐트·타프는 바닥 레이어**, 가구·수납·화기는 그 위 레이어로 그려집니다. → 텐트 안에 침대·테이블을 놓는 **내부 배치**는 겹침 경고가 없습니다.
- 경고가 뜨는 경우: **텐트↔텐트/타프**, **가구·수납·화기끼리**, **차량이 끼는 겹침**, **장애물(나무·배전함)과의 겹침**, **사이트 밖 이탈**.

## 장비 모양
- 위에서 본 실제 장비 모습으로 그립니다. **텐트 7종은 제품별로** — 빌리지 5.0(어두운 플라이 지붕·앞 캐노피·옆 메쉬창), 야크돔 450(지오데식 3폴대·현관), 모델V·티맥스(아치 폴대 4~5개·큰 메쉬창·앞 미니타프), 라움 미니(X폴대·그라운드시트), 폴러 투맨(크로스 폴대·둥근 문), 지오에어(굵은 에어빔·넓은 창), **타프**(렉타=중앙 능선+사이드 폴대, 헥사=6각 윙, 메인 폴대·가이라인), **야전침대**(프레임·베개·매트선), **테이블/IGT**(우드 슬랫·버너 칸), **의자**(등받이·좌판·팔걸이), **카고박스/쿨러/쉘프**(뚜껑 리브·버클·선반 칸), **화로대**(팔각 받침·그릴·불씨), **차량**(둥근 차체·앞뒤 유리·사이드미러·루프레일·헤드/테일램프, 코나 아이언맨 레드 루프·보닛 + 골드 포인트, 레이 박스카), **나무**(잎 실루엣), **배전함**(외함 + ⚡).

## 글씨 방향
- 장비를 선택하면 **글씨 가로(0°) / 세로(90°) / 180° / 270°**, **↔ 반전**(좌우·상하), **글씨 위치**(중앙·위·아래·왼쪽·오른쪽)를 바꿀 수 있습니다. 장비 수정 모달에서도 같습니다.
- 바꿈 값은 배치 데이터에 저장되어 **새로고침·배치안 저장·JSON 백업·도면 PNG**에 그대로 반영됩니다.

## 🧊 3D 보기
- 상단 **📐 2D / 🧊 3D**로 전환합니다. 사이트 크기·바닥(데크/파쇄석/잔디)·장비 위치·회전·실제 높이를 그대로 3D로 세웁니다.
- 텐트는 **제품별 실제 외관**으로 조립합니다 — 빌리지 5.0(베이지 본체 + 차콜 플라이·지붕 능선 폴대·앞 어닝과 폴대 2개·옆 메쉬창), 야크돔(지오데식 돔 + 폴대 아치 3줄 + 현관), 터널형(아치 폴대·에어빔·큰 창·출입문), 라움(면 돔 + X폴대 + 앞뒤 문 + 바닥 자락), 폴러(컴팩트 돔 + 둥근 문), 지오에어(굵은 에어빔 캐빈). 차량은 SUV 해치백 실루엣(코나=레드 루프·보닛 아이언맨)으로 트렁크가 튀어나오지 않습니다. 타프는 **메인 폴대 2개(2.4m) 능선 + 사이드 폴대(1.8m) ㅅ자 지붕**(렉타)과 **6각 윙**(헥사)으로 세우고 가이라인·팩까지 표현합니다.
- 기본은 **실제 외관**이고, **🔍 투시**를 누르면 텐트·타프만 반투명이 되어 안에 놓은 침대·테이블까지 보입니다.
- **드래그로 360° 궤도 회전**, **휠·핀치로 확대**, **🎯 시점 초기화**로 처음 시점.
- 3D 라이브러리(three.js r160)는 저장소에 포함되어 있어 오프라인에서도 뜨고, 혹시 불러오지 못하면 2D 도면으로 안전하게 남습니다.

## 조작
- 카드 탭 → 배치 / 드래그 → 이동(10cm 스냅) / 선택 후 **↻ 손잡이** 또는 −15°·+15°·+90°·0° → 회전
- 두 손가락 확대·축소, 마우스 휠, 우측 위 ＋/−/맞춤 버튼
- 선택 장비의 **가로·세로·가이(cm)** 를 그 자리에서 수정, **이름·모양**에서 모양·출입문·색상 수정
- **✨ 자동 배치**: 차량은 아래쪽 주차, 큰 텐트는 위쪽, 가구는 텐트 안에 줄 맞춰 정리 (장애물 회피)
- **＋ 장비**: 상단 툴바 **＋ 장비** 또는 장비함 맨 위 **＋ 장비 추가** → 카테고리·모양 칩, 실측(cm)·가이·색상, **모양 미리보기**, **바로 놓기**까지 한 화면에서.
- **💨 바람**: 켜기/끄기, 45°씩 회전. 화로대·난로를 놓으면 바람이 불어가는 쪽으로 연기가 표시됩니다.
- **배치안** 탭에 이름 붙여 여러 개 저장/불러오기/삭제, **도면 PNG**로 이미지 저장, **JSON** 백업/복원

## 파일
- `index.html` — 화면 구조
- `styles.css` — 반응형 스타일 (모바일 하단 시트 / PC 우측 패널)
- `app.js` — 상태·기하 계산(겹침 판정)·캔버스 렌더·3D 씬·자동 배치·저장
- `three.module.min.js` — 3D 보기용 three.js r160 (로컬 포함, 오프라인 대응)
